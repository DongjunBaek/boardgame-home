# 내 보드게임

내가 가진 보드게임을 관리하는 개인용 사이트입니다. 내 PC에서만 열립니다 (다른 기기에서는 접속할 수 없음).

## 켜기·끄기

- **켜기:** `start.bat`을 더블클릭하면 서버가 켜지고 브라우저가 열립니다 (http://127.0.0.1:8000).
  - 이미 켜져 있으면 브라우저만 엽니다.
  - 바탕화면에 두려면: `start.bat` 오른쪽 클릭 → 보내기 → 바탕 화면(바로 가기 만들기)
- **끄기:** 작업 표시줄의 **'내 보드게임 서버'** 창을 닫습니다.

## 쓰는 법

- **찾기:** 위쪽 칸에서 제목·제작사 검색, 장르, 제작사(게임 수 표시, 띄어쓰기·대소문자가 다른 표기는 한 묶음), "N명 가능", "N분 이하", 해봤음, 빈칸 있는 것만으로 거릅니다. 열 머리를 누르면 정렬되고, '제작사'로 정렬하면 제작사끼리 모입니다.
- **바로 고치기:** 표에서 제작사·인원·시간·정가·낸 가격(칸을 눌러서 적고 Enter, Esc는 취소, 비우면 지움), 개수(−/+), 해봤음 체크, 별점(같은 별을 다시 누르면 지움)을 바로 고칩니다. 인원은 `2-4인, 5+gm`처럼 쉼표로 여러 개 적을 수 있습니다.
- **자세히 고치기:** 제목을 누르면 상세 창이 열립니다. 게임 정보·내 정보·구입 정보를 고치고, 삭제도 여기서 합니다.
- **게임 추가:** 오른쪽 위 **[+ 게임 추가]**. 같은 제목(띄어쓰기 무시)은 추가되지 않습니다.

### 엑셀로 한꺼번에 고치기

1. **[엑셀 내려받기]** → 엑셀에서 고치기 → **[엑셀 올리기]**
2. 바뀔 내용을 먼저 보여 줍니다. **[적용]**을 눌러야 저장됩니다.

| 규칙 | 설명 |
|---|---|
| 빈칸 | 그대로 둡니다 |
| `-` | 그 칸을 지웁니다 (제목·개수·해봤음은 지울 수 없음) |
| 게임 ID가 빈 행 | 새 게임으로 추가합니다 |
| 엑셀에서 지운 행 | 사이트에서는 지우지 않습니다 (삭제는 상세 창에서) |
| 오류가 있는 행 | 하나라도 있으면 적용하지 않습니다. 고쳐서 다시 올립니다 |
| 미리보기 뒤에 화면에서 고친 경우 | 적용하지 않습니다. 다시 올려 미리보기부터 합니다 |

엑셀 안의 **'안내'** 시트에 적는 형식이 있습니다.

### 빈칸 채우기

**'빈칸 있는 것만'**을 체크하면 옆에 **'빈칸 채우기용 엑셀 받기'**가 나옵니다. 인원·시간·정가가 빈 게임만 담기고, 채울 칸은 주황색입니다.
게임 상자나 공식 판매처에서 확인한 값만 적고, 모르면 빈칸으로 둡니다. 정가는 할인 전 가격입니다.

## 데이터와 백업

| 위치 | 내용 |
|---|---|
| `data/collection.json` | 보유 게임 목록 (이 파일 하나가 전부입니다) |
| `data/backups/` | 저장할 때마다 직전 상태. 최근 50개 + 최근 30일의 날마다 첫 백업을 남깁니다 |

- `data/`는 git에 올라가지 않습니다. **가끔 `data/` 폴더를 다른 곳(외장 디스크, 클라우드 폴더 등)에 복사해 두세요.**
- **예전 상태로 되돌리기:**
  1. 서버를 끕니다.
  2. 지금 `data/collection.json`을 다른 이름으로 복사해 둡니다 (되돌린 뒤 비교·복구용).
  3. `data/backups/`에서 원하는 시각의 파일(`collection-날짜-시각.json`)을 `data/collection.json`으로 복사합니다.
  4. 서버를 켭니다.

## 처음 설치 (다른 PC에 옮길 때)

Python 3.10 이상과 Node.js가 필요합니다. 저장소 폴더에서:

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r backend/requirements.txt
npm --prefix frontend install
```

그다음 `data/collection.json`을 복사해 넣고 `start.bat`을 실행합니다.

## 개발

| 할 일 | 명령 |
|---|---|
| 서버 테스트 | `.venv/Scripts/python -m pytest` |
| 화면 테스트 | `npm --prefix frontend test` |
| 화면 빌드 | `npm --prefix frontend run build` (`start.bat`이 화면 코드가 바뀌었으면 알아서 합니다) |
| 개발용 실행 | `.claude/launch.json`의 `backend-dev`(8000) + `frontend-dev`(5173) |
| 실데이터 없이 시험 | `data/collection.json`을 `data-sandbox/`에 복사하고 `app-sandbox`(8001)로 실행 |

- 테스트는 임시 폴더만 쓰고, `data/`가 바뀌면 실패합니다.
