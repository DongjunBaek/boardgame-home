# 내 보드게임

내가 가진 보드게임을 관리하는 개인용 사이트입니다. 내 PC에서만 열립니다 (다른 기기에서는 접속할 수 없음).

## 켜기·끄기

- **켜기:** `start.bat`을 더블클릭하면 서버가 켜지고 브라우저가 열립니다 (http://127.0.0.1:8000).
  - 이미 켜져 있으면 브라우저만 엽니다.
  - 바탕화면에 두려면: `start.bat` 오른쪽 클릭 → 보내기 → 바탕 화면(바로 가기 만들기)
- **끄기:** 작업 표시줄의 **'내 보드게임 서버'** 창을 닫습니다.

## 쓰는 법

- **메뉴 (왼쪽):** 대시보드 · 내 보드게임 목록 · 스토어 · 동아리 회비 관리 · 회계록 · 게시판 · 관리자 메뉴. 처음 화면은 대시보드이고, 아직 기능이 없는 메뉴는 '준비 중'으로 나옵니다. 게임 표는 **내 보드게임 목록**에 있습니다.
- **대시보드 (마을):** 픽셀아트 마을에서 캐릭터를 걷게 합니다. 방향키·WASD로 걷고, 땅을 누르면 그 자리로 갑니다. 건물을 누르거나 문 앞에서 위로 걸으면 그 건물 창이 열립니다 (Esc로 닫기). 마지막에 서 있던 자리는 저장됩니다.
  - **밭:** 작물이 저절로 자라 코인이 쌓입니다 (화면을 꺼 둔 동안에도 12시간까지). 밭 창에서 **[거두기]**를 누르면 왼쪽 위 코인에 더해집니다. 지도의 작물이 다 자라 보이면 가득 찬 것입니다.
  - **연구소:** 코인을 써서 작물 레벨을 올립니다 (LV2 코인 300, LV3 코인 1,500). 레벨이 오르면 시간당 코인이 늘고 밭 작물이 바뀝니다. 올리기 전에 밭에 쌓인 코인은 자동으로 먼저 거둡니다.
  - **뽑기 상점:** 코인 100개로 한 번 뽑습니다. 가구나 코인·크리스탈이 나오고, 얻은 가구는 상점 창 아래 '가진 물건'에 모입니다.
  - 집은 만드는 중이라 지금은 '준비 중'으로 나옵니다.
  - 그림: Sprout Lands by Cup Nooble · 글꼴: Galmuri. 자세한 출처는 `frontend/public/village/CREDITS.md`에 있습니다.
- **스토어 바로가기 (왼쪽 '스토어'를 눌러 펼침):** 스토어 이름을 누르면 새 탭에서 그 스토어가 열립니다. 옆 숫자는 판매 링크가 그 스토어인 내 게임 수이고, 누르면 목록 화면으로 가서 그 게임들로 걸러집니다 (다시 누르면 풀림).
  - 처음 목록은 게임들의 판매 링크로 자동으로 만들었습니다. **[편집]**에서 이름·주소·묶음·메모를 고치고, 추가·삭제합니다. 묶음은 고르거나 새로 적습니다.
- **장르 탭:** 표 위의 탭(전체 / 보드게임 / 머더미스터리)으로 장르를 나눠 봅니다. 장르가 없는 게임이 있으면 '미분류' 탭이 생깁니다.
- **동아리 회비 관리:** 회원 탭에서 회원을 추가하고, 오른쪽 '회비 구분'에서 구분별 월 금액을 적습니다. 납부 현황표의 칸을 누르면 그 달 납부·면제를 기록합니다 (몇 달 치를 한 번에 적을 수도 있음). 지난 달인데 기록이 없으면 '미납'으로 보이고, 그만둔 회원은 지우지 말고 상태를 '탈퇴'로 바꿉니다.
- **회계록:** 동아리 돈의 입금·출금과 잔액을 봅니다. **[입출금 기록]**으로 지출·후원 등을 적고, 회비 화면에서 적은 납부는 '회비' 입금으로 자동으로 나옵니다 (고치는 것은 회비 화면에서). 탭으로 입금·출금, 위쪽에서 분류·달·연도를 고릅니다.
- **찾기:** 위쪽 칸에서 제목·제작사 검색, 제작사(게임 수 표시, 띄어쓰기·대소문자가 다른 표기는 한 묶음), "N명 가능", "N분 이하", 해봤음, 빈칸 있는 것만으로 거릅니다. 열 머리를 누르면 정렬되고, '제작사'로 정렬하면 제작사끼리 모입니다.
- **바로 고치기:** 표에서 제작사·인원·시간·정가·구매가격(칸을 눌러서 적고 Enter, Esc는 취소, 비우면 지움), 개수(−/+), 해봤음 체크, 별점(같은 별을 다시 누르면 지움)을 바로 고칩니다. 인원은 `2-4인, 5+gm`처럼 쉼표로 여러 개 적을 수 있습니다.
- **자세히 고치기:** 제목을 누르면 상세 창이 열립니다. 게임 정보·내 정보·구입 정보를 고치고, 삭제도 여기서 합니다.
- **게임 추가:** 목록 화면 제목줄 오른쪽 **[+ 게임 추가]**. 같은 제목(띄어쓰기 무시)은 추가되지 않습니다.

### 엑셀로 한꺼번에 고치기

1. 목록 화면 제목줄의 **[엑셀 내려받기]** → 엑셀에서 고치기 → **[엑셀 올리기]**
2. 바뀔 내용을 먼저 보여 줍니다. **[적용]**을 눌러야 저장됩니다.

| 규칙 | 설명 |
|---|---|
| 빈칸 | 그대로 둡니다 |
| `-` | 그 칸을 지웁니다 (제목·개수·해봤음은 지울 수 없음) |
| 게임 ID가 빈 행 | 새 게임으로 추가합니다 |
| 엑셀에서 지운 행 | 사이트에서는 지우지 않습니다 (삭제는 상세 창에서) |
| 오류가 있는 행 | 하나라도 있으면 적용하지 않습니다. 고쳐서 다시 올립니다 |
| 미리보기 뒤에 화면에서 고친 경우 | 적용하지 않습니다. 다시 올려 미리보기부터 합니다 |

엑셀 안의 **'안내'** 시트에 적는 형식이 있습니다.

### 빈칸 채우기

**'빈칸 있는 것만'**을 체크하면 옆에 **'빈칸 채우기용 엑셀 받기'**가 나옵니다. 인원·시간·정가가 빈 게임만 담기고, 채울 칸은 주황색입니다.
게임 상자나 공식 판매처에서 확인한 값만 적고, 모르면 빈칸으로 둡니다. 정가는 할인 전 가격입니다.

## 데이터와 백업

| 위치 | 내용 |
|---|---|
| `data/collection.json` | 보유 게임 목록 (이 파일 하나가 전부입니다) |
| `data/stores.json` | 스토어 바로가기 목록 |
| `data/club_*.json` | 동아리 회비(구분·회원·납부 기록)와 회계록 |
| `data/village.json` | 대시보드 마을 상태 (재화, 작물 레벨, 캐릭터 자리 등) |
| `data/backups/` | 저장할 때마다 직전 상태. 최근 50개 + 최근 30일의 날마다 첫 백업을 남깁니다 |

- `data/`는 git에 올라가지 않습니다. **가끔 `data/` 폴더를 다른 곳(외장 디스크, 클라우드 폴더 등)에 복사해 두세요.**
- **예전 상태로 되돌리기:**
  1. 서버를 끕니다.
  2. 지금 `data/collection.json`을 다른 이름으로 복사해 둡니다 (되돌린 뒤 비교·복구용).
  3. `data/backups/`에서 원하는 시각의 파일(`collection-날짜-시각.json`)을 `data/collection.json`으로 복사합니다.
  4. 서버를 켭니다.

## 처음 설치 (다른 PC에 옮길 때)

Python 3.10 이상과 Node.js가 필요합니다. 저장소 폴더에서:

```bash
python -m venv .venv
.venv/Scripts/python -m pip install -r backend/requirements.txt
npm --prefix frontend install
```

그다음 `data/collection.json`을 복사해 넣고 `start.bat`을 실행합니다.
