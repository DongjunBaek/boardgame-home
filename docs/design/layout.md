## 주소

메뉴 정의는 `frontend/src/lib/nav.ts` 한곳에 둔다. 사이드바와 Routes가 같은 정의를 쓴다.

| 주소 | 메뉴 | 화면 | 상태 |
|---|---|---|---|
| `/` | 대시보드 | `VillagePage` (픽셀아트 마을, [plan/v3-village.md](../plan/v3-village.md)) | 진행 중 (1~5단계 완료: 바탕·밭·연구소·상점·집) |
| `/games` | 내 보드게임 목록 | `GamesPage` | 완료 (v1 표 화면) |
| (없음) | 스토어 | 사이드바에서 펼침 (`StoreSidebar`) | 완료 |
| `/club/dues` | 동아리 회비 관리 | `ClubDuesPage` | v1 완료 (현황표·회원) |
| `/club/ledger` | 회계록 | `LedgerPage` | v1 완료 (입출금·잔액, 회비 자동 입금) |
| `/board` | 게시판 | `PlaceholderPage` | 준비 중 |
| `/admin` | 관리자 메뉴 | `PlaceholderPage` | 준비 중 |
| 그 밖 | | `/`로 보낸다 | |

## 부분별 규칙

- **상단바:** 로고를 누르면 `/`로 간다. 오른쪽 `.appbar-slot`은 나중에 넣을 기능 자리다. 동작하는 기능만 넣는다.
- **사이드바:**
  - 켜진 메뉴만 `--accent-soft` 바탕에 `--accent` 글자로 보인다.
  - 스토어는 처음에 접혀 있다. 펼침 상태는 브라우저에 기억한다 (`localStorage` `nav.storesOpen`).
  - 관리자 메뉴는 구분선 아래 맨 밑에 둔다.
- **목록 화면 제목줄:** 제목 · 안 해봄 수 · (오른쪽) 엑셀 내려받기 · 엑셀 올리기 · [게임 추가]
- **토스트:** 목록 화면은 입력창 위, 입력창이 없는 화면(회비)은 화면 아래 같은 자리에 뜬다 (`components/Toast.tsx`).
- **좁은 화면(760px 이하):** 상단바 → 사이드바(최대 40vh) → 본문 순서로 쌓는다.
