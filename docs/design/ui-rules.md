# 화면 디자인 규칙

갱신: 2026-10-09. 앱 틀(상단바·사이드바·주소)은 [layout.md](layout.md)에 있다.

**방향:** Notion처럼 차분한 표에 Claude 데스크톱·Discord 같은 앱 틀을 더한다. 보드게임 앱다운 느낌은 상단바 트랙 띠와 제목 앞 표지에서만 낸다.
"AI 기능이 들어갈 것 같은" 도구 느낌을 내되, 실제로 없는 기능을 흉내 내는 단추는 만들지 않는다. 기능이 없는 메뉴는 '준비 중' 화면만 보여 준다.

## 틀

- **상단바**(`.appbar`): 로고 + "내 보드게임". 오른쪽 칸은 나중에 넣을 기능 자리다.
- **사이드바**: 메뉴 6개를 둔다. 스토어는 펼쳐서 바로가기 목록을 보여 준다 (Discord 채널 목록처럼).
- **가운데**: 화면마다 제목줄(`.page-head`) → 내용(`.content`)
- **목록 화면:** 장르 탭(둥근 단추 묶음) → 표 → 아래 입력창(`.composer`)
  - 입력창 윗줄은 검색, 아랫줄은 거르기 칩이다. 새 거르기는 여기에 칩으로 더한다.
  - 알림은 입력창 위에 뜨는 토스트로 보여 준다.
- 새 메뉴를 더할 때는 `frontend/src/lib/nav.ts`에 정의하고, [layout.md](layout.md)의 주소 표를 고친다.

## 색

- `styles.css` 맨 위 토큰만 쓴다. 컴포넌트 CSS에 색 값을 바로 적지 않는다.
- 밝은 화면은 따뜻한 회색, 어두운 화면은 Discord 같은 푸른 회색이다.
- 포인트 색은 흙빛 주황(`--accent`) 하나다. 고른 것·켜진 것·주요 단추에만 쓴다.
- 장르 색: 보드게임은 이끼색(`--chip-board*`), 머더미스터리는 와인색(`--chip-murder*`)이다.
- 트랙 띠 색은 `--track-1~4`이고, 띠에만 쓴다.
- 금지: 보라·파랑 그라데이션, 글자 그라데이션, 유리처럼 비치는 카드, 네온

## 글꼴·아이콘

- 글꼴은 Pretendard(npm `pretendard`)다. 기본 14px이고, 제목은 굵게(700) + 자간을 살짝 좁게 한다.
- 아이콘은 `lucide-react`를 쓴다. 글자 기호(✕ ✎ ↗ ▲)를 아이콘 대신 쓰지 않는다. 장식용 아이콘엔 `aria-hidden="true"`를 붙인다.

## 모양

- 둥근 정도: 작은 것 6px, 카드·표 10px, 입력창 18px, 칩·탭 999px
- 선은 얇게(`--border`) 긋고, 그림자는 토큰(`--shadow-sm/md/lg`)만 쓴다.
- 표: 머리줄은 작고 흐리게(12px, `--muted`) 한다. 줄 구분선만 두고 세로선은 없다.
- **꾸밈은 두 곳뿐이다.**
  - 제목 앞 작은 표지(`GameThumb`): 사진이 없으면 첫 글자를 장르 색 타일에 넣는다.
  - 상단바 아래 3px 게임판 트랙 띠: 네 색 칸을 끊어 그린다. 번지는 그라데이션이 아니다.
  - 다른 곳에는 꾸밈을 더하지 않는다.
- 움직임은 짧게(0.1~0.2초) 한다. 화면이 출렁이는 효과는 쓰지 않는다.

## 확인

- 고친 뒤 `npm --prefix frontend run build`를 돌리고, 밝은·어두운 화면을 둘 다 스크린샷으로 본다. 자세한 방법은 [dev/testing.md](../dev/testing.md)에 있다.
