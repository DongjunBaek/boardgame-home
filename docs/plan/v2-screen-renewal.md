# v2 화면 개편: 메뉴 틀과 상단바

작성: 2026-10-09 · 상태: 2단계 완료 (2026-10-09)

## 왜

v1은 게임 표 한 화면이었다. 대시보드·동아리 회비·게시판·관리자 기능을 하나씩 붙이려면 메뉴 틀이 먼저 있어야 한다.
이번 개편에서는 메뉴 이름과 화면 이동만 만든다. 기능은 메뉴마다 따로 계획한다 ([features/](../features/)).

## 정한 것 (2026-10-09 질문 답변)

| 질문 | 결정 |
|---|---|
| 화면 이동 | **react-router**. 메뉴마다 주소가 있다 → [0001](../decisions/0001-react-router.md) |
| 사이드바 메뉴 | 대시보드 · 내 보드게임 목록 · 스토어 · 동아리 회비 관리 · 게시판 · 관리자 메뉴 → [0002](../decisions/0002-sidebar-menu.md) |
| 스토어 메뉴 | 사이드바에서 펼쳐 지금의 스토어 바로가기 목록을 그대로 보여 준다 |
| 첫 화면 | 대시보드 |
| 사이트 이름 | 내 보드게임 (그대로) |
| 게임 추가·엑셀 단추 | 목록 화면 제목줄 오른쪽 |
| 상단바 오른쪽 | 비워 둔다. 동작하지 않는 단추는 만들지 않는다 |

## 1단계에서 바뀐 코드

- `frontend/src/main.tsx`: `BrowserRouter`로 감쌌다.
- `frontend/src/App.tsx`: 데이터 상태는 그대로 둔다. 메뉴를 옮겨도 거르기가 남는다. 화면은 AppBar + SideNav + Routes로 바꿨다.
- `frontend/src/lib/nav.ts`: 메뉴 정의(주소·이름·아이콘)를 한곳에 모았다.
- `frontend/src/components/AppBar.tsx`, `SideNav.tsx`: 새로 만들었다. `StoreSidebar.tsx`는 그대로 SideNav 안에서 펼친다.
- `frontend/src/pages/GamesPage.tsx`: 예전 App의 본문을 옮겼다. `PlaceholderPage.tsx`는 '준비 중' 화면이다.
- `frontend/src/styles.css`: 새로 넣은 것은 `.appbar`(+트랙 띠), `.nav*`, `.page-head`, `.page-actions`, `.ghost-btn`, `.placeholder`, 토큰 `--track-1~4`다. 지운 것은 `.topbar`, `.new-btn`, `.sidebar-foot`, `.side-item`이다.
- `frontend/public/favicon.svg`: Vite 기본 번개를 흙빛 주황 주사위로 바꿨다.
- 백엔드는 바꾸지 않았다. 이미 모든 화면 주소에 `index.html`을 준다.

## 확인 (2026-10-09)

- 테스트: 화면 93개 통과, oxlint 통과, 빌드 통과
- `app-sandbox`(8001)에서 확인한 것
  - 메뉴 6개로 이동하고 주소가 바뀐다.
  - `/games`에서 새로고침해도 화면이 뜬다. 모르는 주소는 `/`로 간다.
  - 스토어가 펼쳐지고 접힌다. 숫자를 누르면 `/games`로 가서 걸러진다.
  - [게임 추가]를 누르면 상세 창이 열린다.
  - 밝은·어두운 화면과 폭 375px를 확인했다. 콘솔 오류는 없다.
- 확인 못 함: 엑셀 올리기는 단추 자리만 옮겼고 실제 파일로 다시 시험하지 않았다. 코드 경로는 그대로다.
