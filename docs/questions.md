# 물어볼 질문

나중에 바꿔도 되는 것은 기본값으로 진행하고 여기에 모은다. 답을 받으면 해당 문서에 반영하고 아래 "정함"으로 옮긴다.

## 열린 질문 (2026-10-09, v2 화면 개편 1단계)

| # | 질문 | 지금 기본값 |
|---|---|---|
| 1 | 메뉴 이름 표기 ("내 보드게임 목록" vs "내 보드게임"), 아이콘 | 사용자가 말한 이름 그대로. 아이콘은 LayoutDashboard·Library·Store·Wallet·MessageSquare·Shield |
| 2 | 주소 이름 | `/`, `/games`, `/club/dues`, `/board`, `/admin` |
| 3 | 상단바 높이·트랙 띠 모양·로고 표지 (주사위 대신 미플 등 직접 그린 SVG) | 52px, 이끼·주황·와인·별색 4칸 띠, lucide `Dices` 타일 |
| 4 | 파비콘 모양 | 흙빛 주황 바탕의 흰 주사위(눈 3개) |
| 5 | 스토어 메뉴를 처음에 펼쳐 둘지 | 접어 둠 (목록이 길어 아래 메뉴를 가림). 펼침 상태는 기억함 |
| 6 | 휴대폰 폭에서 사이드바를 햄버거 메뉴로 바꿀지 | 지금처럼 위로 쌓음 |
| 7 | 대시보드에 무엇을 보여 줄지 | 준비 중 화면 |
| 8 | **큰 방향:** 동아리 회비·게시판·관리자는 여러 사람이 쓰는 기능이다. 지금처럼 "내 PC에서만, 로그인 없음"인 혼자 쓰는 장부로 둘지, 배포·로그인을 할지 | 혼자 쓰는 장부 (v1 그대로). **해당 메뉴의 기능을 만들기 전에 꼭 정한다** |
