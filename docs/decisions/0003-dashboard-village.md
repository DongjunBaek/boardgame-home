# 0003. 대시보드를 픽셀아트 마을 미니게임으로 만든다

날짜: 2026-10-09 · 상태: 정함 (범위). 기술 선택은 기본값이며 1단계에서 확인한다

## 배경
대시보드는 '준비 중'이었다. 사용자가 픽셀아트 마을 컨셉 화면을 보여 주며, 대시보드에서 심심풀이 미니게임을 하고 싶다고 했다.
계획은 [plan/v3-village.md](../plan/v3-village.md)에 있다.

## 결정
- **대시보드 본문만 화면 규칙의 예외로 둔다.** 마을 캔버스와 그 위에 뜨는 패널에서는 다음을 허용한다.
  - 픽셀아트 그림
  - 한글 픽셀 글꼴
  - 토큰에 없는 색
  - 지도 위 캐릭터의 계속되는 움직임
- 상단바·사이드바와 다른 메뉴 화면은 [design/ui-rules.md](../design/ui-rules.md)를 그대로 따른다.
- **'없는 기능을 흉내 내는 단추 금지'는 마을에도 적용한다.** 마을 안 단추는 모두 실제로 동작하는 미니게임 기능이어야 한다. 아직 없는 건물이나 메뉴는 그리지 않는다.
- **기술 (기본값):**
  - 지도와 캐릭터는 PixiJS로 그린다.
  - 지도는 Tiled JSON으로 불러온다.
  - 패널은 React로 만든다.
- **저장:** 서버의 마을 상태 파일에 둔다. 보드게임 데이터와 파일을 나눈다. 밭 보상과 뽑기 결과는 서버가 계산한다.

## 다른 선택지
- **그림 한 장 + 클릭 영역 (1단계):** 쉽지만 캐릭터가 움직이지 않는다. 사용자가 2단계를 골랐다.
- **Phaser:** 게임 기능이 더 많지만 무겁다. 이 앱은 React 화면 안에 지도 하나를 그리면 되므로 PixiJS가 가볍다.

## v1 계획과 달라진 점
