# 0002. 사이드바를 메뉴 6개로 나눈다

날짜: 2026-10-09 · 상태: 정함 (메뉴 이름만. 기능은 메뉴별로 따로 정한다)

## 배경
v1 사이드바는 로고 → 게임 추가 → 스토어 목록 → 엑셀 순서였다. 앞으로 동아리 운영 기능을 더하려고 메뉴 틀을 먼저 만든다.

## 결정
- **메뉴:** 대시보드 · 내 보드게임 목록 · 스토어 · 동아리 회비 관리 · 게시판 · 관리자 메뉴
- **첫 화면:** 대시보드
- **스토어:** 주소 없이 사이드바에서 펼쳐 바로가기 목록을 보여 준다. 숫자를 누르면 목록 화면으로 가서 거른다.
- **로고:** 사이드바에서 새 상단바로 옮긴다. 게임 추가·엑셀 단추는 목록 화면 제목줄로 옮긴다.
- **기능 없는 메뉴:** '준비 중' 화면만 보여 준다. 가짜 단추는 만들지 않는다.

## v1 계획과 달라진 점
[plan/PLAN.md](../plan/PLAN.md)의 "하지 않음"에는 "회원·로그인·권한, 동아리, 회비"가 들어 있었다.
이번에 **동아리 회비·게시판·관리자 메뉴 자리를 만들었다.**
같은 날 [questions.md](../questions.md) 8번에 답을 받았다: **혼자 쓰는 장부로 유지한다.** 로그인·권한·배포는 여전히 하지 않는다. 동아리 기능은 내가 기록하는 장부로 만든다.
