# 0001. 화면 이동은 react-router로 한다

날짜: 2026-10-09 · 상태: 정함

## 배경
v1은 한 화면뿐이라 라우터가 없었다. 메뉴 6개(대시보드·목록·스토어·회비·게시판·관리자)를 만들면서 화면을 나눌 방법이 필요해졌다.

## 결정
`react-router` v7을 쓴다. `main.tsx`에서 `BrowserRouter`로 감싸고, 메뉴마다 주소를 둔다. 주소 표는 [design/layout.md](../design/layout.md)에 있다.

## 이유
- 새로고침·뒤로 가기·북마크가 된다.
- 백엔드(`backend/app/main.py`의 `spa`)가 이미 모르는 주소에 `index.html`을 준다. Vite 개발 서버도 마찬가지다. 그래서 서버는 고칠 것이 없다.
- 상태값으로만 화면을 바꾸면 라이브러리는 줄지만, 새로고침하면 첫 화면으로 돌아간다.

## 따라오는 것
- 게임·스토어·거르기 상태는 `App`에 둔다. 화면을 옮겨도 거르기가 남는다.
- 메뉴 정의는 `frontend/src/lib/nav.ts` 한곳에 둔다.
