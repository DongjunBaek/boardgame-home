## 첫 버전 (v1) 기능

**회비 구분**
- 구분마다 이름과 월 금액을 둔다. 예: 정회원 10,000원, 준회원 5,000원, 면제 0원
- 금액을 바꿔도 지난 납부 기록은 그대로다. 납부할 때 금액을 기록에 함께 적기 때문이다.

**회원 명단**
- 이름, 구분, 가입 월, 상태(활동 / 휴면 / 탈퇴), 메모
- 탈퇴한 회원은 지우지 않고 상태만 바꾼다. 지난 납부 기록을 남기려는 것이다.
- 탈퇴·휴면 기간에는 미납으로 세지 않는다.

**납부 현황표** (화면의 중심)
- 줄은 회원, 열은 달(1~12월)이다. 위에서 연도를 고른다.
- 칸 상태는 넷이다.

| 상태 | 표시 |
|---|---|
| 납부 | 금액과 체크 아이콘 (`--ok`) |
| 미납 | 지난 달인데 기록이 없음. 흐린 빨강 바탕 (`--bad-bg`) |
| 면제 | 흐린 글씨 '면제' |
| 해당 없음 | 가입 전, 아직 안 온 달, 탈퇴 뒤. 비워 둔다 |

- 칸을 누르면 작은 창이 열려 납부 기록을 적는다.
  - 처음 값: 금액 = 그 회원 구분의 월 금액, 낸 날 = 오늘, 방법 = 계좌
  - 고칠 수 있는 것: 금액, 낸 날, 방법(계좌 / 현금 / 기타), 메모
  - [납부] [면제] [기록 지우기]
- 오른쪽 끝 열은 그 해의 미납 개월 수와 미납 금액이다.
- 제목줄 요약: 이번 달 납부 N/M명 · 이번 달 걷힌 금액 · 올해 미납 합계

**데이터 안전장치** (v1 게임 목록과 같다)
- 원자적 쓰기, 저장할 때마다 백업, 미리보기 없는 단건 저장

## 첫 버전에서 하지 않음 (나중에)

- 미납 목록 화면과 안내 문구 복사
- 지출 기록, 잔액, 결산·엑셀 내보내기
- 한 번만 걷는 돈 (MT·참가비·공동구매 분담)
- 동아리 돈으로 산 게임과 '내 보드게임 목록' 연결
- 하지 않음: 회원 로그인, 은행·자동이체 연동, 알림 자동 발송

## 데이터

`data/` 아래 JSON 파일 세 개를 둔다. `backend/app/store.py`의 `load_json`·`save_json`(원자적 쓰기·백업)을 그대로 쓴다.

```jsonc
// data/club_tiers.json  회비 구분
[{ "id": "tier:1a2b", "name": "정회원", "monthly_fee": 10000 }]

// data/club_members.json  회원
[{ "id": "member:3c4d", "name": "김철수", "tier_id": "tier:1a2b",
   "joined": "2026-03", "status": "active",   // active | paused | left
   "status_since": null,                      // 휴면·탈퇴가 시작된 달
   "memo": null }]

// data/club_payments.json  달마다 한 건 (회원 + 달이 열쇠라 따로 ID는 없다)
[{ "member_id": "member:3c4d", "month": "2026-10",
   "kind": "paid",                            // paid | exempt
   "amount": 10000, "paid_on": "2026-10-05", "method": "bank", "memo": null }]
```

- 미납은 저장하지 않고 계산한다. 회원이 활동 중인 지난 달인데 기록이 없으면 미납이다.
- 여러 달을 한 번에 낸 경우는 달마다 기록을 하나씩 만든다. 창의 '몇 달 치'에서 고른다.

## API

| 주소 | 하는 일 |
|---|---|
| `GET /api/club` | 구분·회원·납부 기록을 한 번에 (20명 규모라 충분). 처음 부르면 기본 구분 정회원·준회원(금액 미정)·면제를 만든다 |
| `POST /api/club/tiers`, `PATCH`·`DELETE /api/club/tiers/{id}` | 회비 구분. 쓰는 회원이 있으면 지우지 못한다 (409) |
| `POST /api/club/members`, `PATCH`·`DELETE /api/club/members/{id}` | 회원. 납부 기록이 있으면 지우지 못하고 상태를 탈퇴로 바꾼다 (409) |
| `PUT /api/club/payments/{member_id}/{YYYY-MM}` | 한 칸 기록 (덮어씀). `months`가 2 이상이면 이어지는 달까지 적고, 그 달들에 기록이 있으면 거절 (409) |
| `DELETE /api/club/payments/{member_id}/{YYYY-MM}` | 한 칸 지우기 |
